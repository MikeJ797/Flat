CUS proposed ground-floor apartment - polished Quest 3 VR mock-up
===================================================================

What this version changes
-------------------------
This version is cleaner and more realistic than the first block model. It keeps room labels switched off by default and includes more recognisable furniture and fixtures so you can judge scale more easily.

Included furniture / fixtures
-----------------------------
- Kitchen base units, upper cabinets, worktop, sink, tap, oven, fridge and island with hob/stools.
- Dining table and chairs.
- Sofa, cushions, coffee table, rug and TV/storage unit.
- Bedroom bed, pillows, headboard, bedside tables, wardrobe and small desk/chair.
- Bathroom shower tray, glass shower screen, shower head, WC, basin, vanity and mirror.
- Utility area with washing machine and storage.
- Portico/covered porch with posts, outdoor table/chairs and simple planting.

How to use on Meta Quest 3
--------------------------
1. Unzip the folder.
2. Upload the entire folder to an HTTPS web host. Simple options include Netlify Drop, Cloudflare Pages, GitHub Pages, or your own website hosting.
3. Open the HTTPS URL to index.html in Meta Quest Browser.
4. Press Enter VR.
5. Use the controller/thumbstick movement if supported by the browser session. On desktop, use WASD + mouse.

Important: opening index.html directly from a local folder normally will not launch immersive WebXR. Use HTTPS.

Optional labels
---------------
Labels are off by default for a cleaner walkthrough. On a desktop keyboard, press L to toggle room labels. In Quest, labels will remain off unless you pair/use a keyboard.

Accuracy note
-------------
This is still an approximate visualisation from the PDF, not a CAD/BIM model. It is intended for sense-checking scale, furniture fit and circulation only. It should not be used for construction, planning submission, quotes, or compliance.

Approximate source assumptions from the proposed ground-floor drawing:
- Bathroom / bagno: 5.49 m²
- Utility / anti-rip: 2.77 m²
- Bedroom / camera: 13.42 m²
- Living / soggiorno: 20.14 m²
- Portico / covered porch: 22.50 m²
- Approx. internal height used: 2.61 m

For a more accurate next version, ask the architect for DWG, DXF, IFC, Revit, Archicad or SketchUp files.
